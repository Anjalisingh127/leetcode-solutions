# LeetCode Solutions

A collection of my **Data Structures and Algorithms** solutions from LeetCode, primarily implemented in **Java** as part of my software engineering interview preparation.

## About This Repository

This repository documents my ongoing DSA practice and problem-solving progress. I focus on understanding the reasoning behind each solution rather than only reaching an accepted submission.

For problems where multiple approaches are useful, I work through:

- Brute-force approach
- Improved approach
- Optimal approach
- Time and space complexity
- Important edge cases

## Topics

- Arrays & Strings
- Hashing
- Two Pointers
- Sliding Window
- Linked Lists
- Stacks & Queues
- Binary Search
- Recursion & Backtracking
- Trees & Binary Search Trees
- Heaps
- Graphs
- Greedy Algorithms
- Dynamic Programming

## Language

**Primary Language:** Java

## Problem-Solving Approach

For each problem, I try to answer four questions:

1. What is the simplest correct solution?
2. What is the bottleneck in that approach?
3. Which data structure or algorithm can improve it?
4. What are the final time and space complexities?
